# Support

Use GitHub Issues for reproducible bugs, documentation problems, and feature proposals:

<https://github.com/felixlark/x-use/issues>

Before opening an issue:

1. Run `npm test`.
2. Run `npm run check`.
3. Check `xurl auth status` and the installed version.
4. Remove tokens, cookies, private account identifiers, and private paths from logs.

For security-sensitive reports, use [SECURITY.md](SECURITY.md) instead of a public issue.

This project does not provide X API credits, account recovery, billing support, or authorisation bypasses. Rate-limit and entitlement errors must be resolved with the X developer account that owns the app.
